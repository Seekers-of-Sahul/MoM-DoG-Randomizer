Rebalance

Always included: bug fixes (real random numbers, level cap), swappable equipment, stacking tower items, experience carry-over, magic attack scaling, Goblin line, Slime buff.

Every fight gives experience, and a unit that reaches 100 levels up without a kill.
Buffs the five disciples other than Justice.
Rewritten story, tutorials, encyclopedia, item and spell descriptions; corrected monster and item names.
Rebalanced: every early map offers Law, Neutral and Chaos units (cheap summons for any disciple), flyers, and both humans and monsters. Randomized: all maps, each slot keeps its movement type and a similar level.

Speed

Shorter loading screens, memory card checks and tutorial pop-ups.
Turn off to keep the map music during fights: no music has to load, so battle animations start much faster.

Challenge

Stage select

After every battle, pick the next stage on the Map Mode screen. Progressive opens stages in story order, Shuffled in a random order (stage 22 last).

Draft mode

No summoning. You start with 3 monsters, and after each battle new ones join and you trim your army to a growing limit.

Using the patched file

Put the new .bin next to your other track files and point your .cue's first FILE line at it (or rename it to the original Track 1 name). Without the audio tracks the game freezes after the intro video. Same disc + same seed + same options = same game.

Needs a desktop browser with about 1.5 GB of free memory; nothing is uploaded.
